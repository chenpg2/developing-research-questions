# Question Types and "Some Other Thing" Dimensions

## What makes a question good (beyond the checklist)

The standard list (clear, focused, relevant, novel, tractable) is necessary but not enough. Also ask:

- **Drive:** Does it keep bothering the user? Will they want to keep working on it?
- **Reframing:** Does it recast an unanswered question in a new way?
- **Challenge:** Does it question an assumption the field takes for granted?
- **Method blind spot:** Does it show how past methods hid part of the picture?
- **Innovative approach:** Does it invite a new way of studying the problem?

A question that only fills a gap ("nobody has done X in population Y") can be fine, but check whether it does any of the above.

## Question types

None of these needs a specific falsifiable hypothesis to be worth asking (see Trap 1). The paper names descriptive ("what", including "What happens if ...?"), mechanistic ("how") and normative ("why") questions. This skill splits exploratory out of descriptive and adds the "Typical answer" column and the confirmatory row.

| Type | Form | Example template | Typical answer |
|---|---|---|---|
| Descriptive ("what") | "What do / does ... in situation X?" | "What do people do in XYZ situation?" | Characterization, taxonomy, measurement |
| Exploratory | "What happens if ...?" | "What happens if we remove constraint C?" | Patterns, new phenomena, candidate hypotheses |
| Mechanistic ("how") | "How does A bring about B?" | "How does effect ABC come about?" | Causal pathway, model, mechanism |
| Normative / functional ("why") | "Why do / does ... X and not Y?" | "Why do organisms do X and not Y?" | Function, optimality, evolutionary or rational account |
| Confirmatory (added; not in the paper's list) | "Does X cause / predict Y (by about Z)?" | "Does intervention I improve outcome O?" | Test of a specific falsifiable hypothesis |

Use this to classify the user's question and to suggest reframing it as another type when that opens up a better question.

## "Some other thing" dimensions (Phase 3)

When asking "What if they had done [some other thing] instead?", go through these dimensions. The first six come from the paper; rows marked "extension" were added by this skill. Each can be a small tweak or a major change.

| Dimension | Prompt |
|---|---|
| Analytical approach | A different model, statistic, level of analysis, or way of handling the data? |
| Control condition | Which control would rule out a different explanation? Is the current control actually matched? |
| Stimulus set / materials | Other stimuli, items, compounds, datasets, environments? |
| Data collection technique | A different measurement modality, resolution, timescale, or instrument? |
| Target population / system | Other species, cell types, ages, cultures, clinical groups, scales? |
| Task / paradigm | A different task, manipulation, or experimental design? |
| Framing / theory (extension) | A rival theory's framing of the same data? |
| Scale (extension) | Smaller or larger in time, space, sample size or number of units? |
| Assumption (extension) | Which assumption in the design, if false, would change the conclusion? |

Coverage target: alternatives on at least 3 dimensions before choosing.

## Alternative explanations prompts (Phase 4)

The paper asks for all plausible alternative explanations, confounds and interpretations; these prompts are this skill's own aids for finding them.

- What else, apart from the intended mechanism, could produce the same result?
- What variable covaries with the manipulation?
- Could the measurement itself create the effect?
- Could selection of the sample or stimuli explain it?
- What would a reviewer from a rival theoretical camp say the result shows?
- If the result is null, what are the uninteresting reasons it could be null?
